## Descripción del Proyecto
Aplicación CRUD en Java con arquitectura en capas (modelo, excepciones, dao, dao.impl, servicio, app) y persistencia en *SQLite* mediante *JDBC*. Implementa relaciones 1:N entre Autor y Libro, uso de interfaces genéricas (CrudDAO<T, ID>), consultas parametrizadas con PreparedStatement, manejo de recursos con try-with-resources y validaciones de negocio.
